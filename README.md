# SchoolFlow SaaS

SaaS de gestion d'établissement scolaire, construit avec Next.js et prêt à démarrer localement.

## Fonctionnalités

- Tableau de bord principal
- Statistiques globales
- Gestion des étudiants
- Suivi des enseignants
- Analyse des paiements
- Présence et performance scolaire
- Architecture prête pour extension SaaS

## Démarrage rapide

```bash
npm install
npm run dev
```

Puis ouvrez : http://localhost:3000

## Stack

- Next.js
- React
- TypeScript
- CSS natif

## Objectif

Ce projet sert de base de démonstration pour un SaaS de gestion d'établissement scolaire, extensible vers :
- authentication/admin
- base de données PostgreSQL/Prisma
- modules classes, examens, notes, caisse, calendrier
- déploiement Vercel ou Railway
